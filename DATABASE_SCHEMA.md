# Database Schema Suggestion for Solvra

## Collections

### `users`
Stores user profile information and subscription status.

| Field | Type | Description |
|---|---|---|
| `uid` | String | Unique User ID (from Firebase Auth) |
| `email` | String | User's email address |
| `displayName` | String | User's full name |
| `photoURL` | String | URL to profile picture |
| `credits` | Number | Available AI generation credits |
| `plan` | String | Subscription plan (`free`, `pro`, `enterprise`) |
| `createdAt` | Timestamp | Account creation date |
| `lastLogin` | Timestamp | Last login date |

### `projects`
Stores the projects generated by users.

| Field | Type | Description |
|---|---|---|
| `id` | String | Unique Project ID (Auto-generated) |
| `userId` | String | Reference to the owner's UID |
| `name` | String | Project name (e.g., "My Landing Page") |
| `type` | String | Project type (`landing`, `fullstack`, `mobile`) |
| `prompt` | String | The user's input prompt describing the project |
| `status` | String | Generation status (`draft`, `processing`, `completed`, `failed`) |
| `output` | Map/Object | The generated result (e.g., `{ codeUrl: "...", previewUrl: "..." }`) |
| `createdAt` | Timestamp | Creation date |
| `updatedAt` | Timestamp | Last update date |

### `marketplace_items`
Stores the available apps in the marketplace.

| Field | Type | Description |
|---|---|---|
| `id` | String | Unique Item ID |
| `name` | String | App name (e.g., "LeadSort") |
| `description` | String | Short description |
| `price` | Number | Price in USD (0 for free) |
| `category` | String | Category (`marketing`, `sales`, `utility`) |
| `downloadUrl` | String | URL to download the source code |
| `demoUrl` | String | URL to a live demo |

## Relationships

*   **One-to-Many**: A `User` can have multiple `Projects`.
*   **Many-to-Many**: Users can purchase/download multiple `Marketplace Items` (tracked via a separate `purchases` collection if needed).

## Indexes

*   `projects`: `userId` (Ascending), `createdAt` (Descending) - For listing user projects efficiently.
